# 🌐 Meu Portal de Entretenimento Digital

Projeto desenvolvido como atividade prática para o Curso Técnico em Desenvolvimento de Sistemas (ETEC).

## 🛠️ Tecnologias Utilizadas
- **HTML5**: Estruturação semântica da página.
- **CSS3**: Estilização avançada com **Flexbox** para layout responsivo.
- **CSS Reset (Eric Meyer)**: Padronização entre diferentes navegadores.

## 📂 Estrutura de Arquivos
- `portal.html`: Arquivo principal da página web.
- `estilo.css`: Folha de estilo customizada do portal.
- `reset.css`: Arquivo de reinicialização de estilos base.
- `relatorio.md`: Registro textual das interações com a IA.
